# data-science-analise-exploratoria
Início da análise exploratória de um conjunto de dados do MovieLens.

O arquivo utilizado foi ratings.csv, que contém 100 mil avaliações dadas a cerca de 9 mil filmes filmes.

Os campos deste dataset são os seguintes:

- ID do usuário (userId), a pessoa que deu a nota;
- ID do filme (movieId);
- nota (rating);
- data da atribuição dessa nota (timestamp).
