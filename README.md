# data-science-analise-exploratoria
Início da análise exploratória de um conjunto de dados do MovieLens.

Os arquivos utilizados foram:

1. **ratings.csv**, que contém 100 mil avaliações dadas a cerca de 9 mil filmes filmes.

Os campos deste dataset são os seguintes:

- ID do usuário (userId), a pessoa que deu a nota;
- ID do filme (movieId);
- nota (rating);
- data da atribuição dessa nota (timestamp).

2. **tmdb_5000_movies.csv**, que contém as informações relativas a 5 mil filmes.

Alguns dados que figuram na base são:

- budget: o valor do orçamento do filme;
- genres: os gêneros do filme;
- homepage: a página do filme na internet;
- id: identificação do filme;
- keywords: as palavras-chave associadas ao filme.
